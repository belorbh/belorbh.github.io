# Belor — app da loja

App (PWA) da Belo Estilo BH: vendas ao vivo, metas, microdados e boletim do dia, com notificação no iPhone a cada venda.

- Abra **https://belorbh.github.io** no Safari do iPhone → Compartilhar → **Adicionar à Tela de Início**.
- Os números da loja **não ficam aqui**: o app busca no servidor da loja e só mostra depois do código de acesso.
- Este repositório tem só o app (HTML, CSS e JS), sem dependências.
